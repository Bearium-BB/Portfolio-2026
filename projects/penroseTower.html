Overview

  • Role: Programmer, on a team of 4 with another programmer and two artists.
  • Engine: Unity.
  • Genre: endless metroidvania about casting spells until death.

Movement

I built the physics-based movement system. Penrose Tower is about a constant climb, so traversal needed to feel fast and responsive, and I used physics for it rather than a hand-animated controller so that jumps, falls and momentum felt natural.

GIF: climbing the tower

Spellcasting

The spellcasting system is where most of my time went. You combine multiple elements, and each combination produces its own effect. I set the system up so that adding a new spell is mostly a matter of adding data, which let the team iterate on content quickly instead of writing new code for every idea.

GIF: combining two elements into a spell

Enemy Animation

I also built an event-driven animation framework. Animations are triggered by events instead of being hard-wired to each enemy, so the same behavior can be reused across different enemy types with very little extra work.
